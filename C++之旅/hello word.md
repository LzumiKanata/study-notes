- 重点
    cout <<" hello word "<< endl 
- 变量
    方便才做内存里的工具
    方便管理内存空间，其实就是将内存赋值给变量
    因而，变量本质上就是bit的代称，故而有数字有字符串
    变量的语法：
    数据类型  变量名  =  变量初始值
- 常量
    用于记录不可修改的数据
    如，一些必定发生的常识
    C++有两种定义常量的的语法，为以下
    1：#define /宏常量（#define  常量名  常量值）
    通常在文件上方定义，表示一个常量
    
    2：const /修饰变量（数据类型  变量名=常量值）
    通常在变量定义前加上关键字const，修饰该变量为常量，不可修改
- 标识符规则
    不能为关键字
    只能由字母、数字、下划线组成
    第一个字符必须为字母或下划线
    标识符中的字母区分大小写
    取名时争取见文知意，便于阅读（建议）
- 数据类型
    short（短整型）——2字符
    int（整形）——4字节
    long（长整型）——Windows为4字节、Linux为4字节（32位），8字节（64位）
    long long （长长整型）——8字节
    字节数不同导致取值范围不同
- sizeof关键字
    sizeof关键字可以统计数据类型所占的内存大小
    语法：
    sizeof（数据类型/变量）
- 实型/浮点型
    1. 单精度  float
    2. 双精度  double
    float为4字节，有7位有效数字
    double为8字节，有15-16位有效数据
    （3.1415，其中有5位有效数字）
    
    其中float函数为下
        float f1 = 3.14f;（如若3.14后不加f，则VV会将3.14默认为double类型）

- 科学计数法
    如3e2 = 3 * 10^2
     3e-2=3 * 10^-2
- 字符型
    作用：字符型变量用于显示单个字母
    语法：char ch = ‘a’（char  字符名称  =  ‘  字符  ’  ） 
    字符型变量只占用个1字节
