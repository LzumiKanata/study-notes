# 苏美尔文明
- 伊拉克的土地十分肥沃，这是苏美尔文明诞生的重要条件【缺乏降雨，要开凿水渠】
- 社会需求是他们创造了楔形文字
- 因为畏惧自然灾害，他们用茅草与泥巴为主要原材料所组成的泥砖建造了神庙【大洪水记事板】
- 苏美尔最早建立的城市叫做埃利都，绝区零中的新爱利都或许取源于此
- 泥砖所建的建筑挡不住岁月的侵蚀
- 吉尔伽美什的神话诞生于埃利都的后继者乌鲁克
- 阿卡德大军政府北方的马里语埃布拉两大城邦，将波斯湾与地中海之间的文明统一在一个政权之下，成立了阿卡德第一帝国，帝国与王国
- 拉格什第二城邦
- 乌尔第三王朝
- 乌尔的神庙，其属于塔庙，最高处是月神庙 
# 巴比伦与亚述
- 汉谟拉比建立古巴比伦王国
- 乌图与汉谟拉比，君权神授
- 亚述是埃及的前置软件
- 亚述的塔庙，阶梯呈螺旋形
- 亚述人发明了拱形结构【石拱】
- 亚述灭国，新巴比伦建立
- 米底公主思念自己家乡的树，巴比伦国王尼布甲尼撒建造了边长超过120米，高度超过20米的大型台地园世界七大奇迹
- 新巴比伦中心有着通天塔，让人类文子语言不通的通天塔，巴别塔，变乱他，巴比伦塔。
