# 通信职业道德（单选）

- 职业的定义：人们在社会中所从事的专门业务和对社会承担的特定职责，并以此作为重要的生活来源的社会活动

- 职业道德：人们从事正当的社会职业，并在其履行职责的过程中，再思想和行为上应当遵循的具有自身职业特征的的道德准则和行为规范。
  其包括
    职业义务：从业人员对本职、社会所承担的道德使命和责任
    职业良心：从业人员在在履行职业义务过程中形成的一种道德意识
    职业荣誉：从业人员对履行职业义务的社会价值所形成的自我意识
    职业信誉：包含职业职业信用和职业名誉、社会承认本行业的活动价值
    职业尊严：本行业社会价值和道德价值的自我意识和评价的综合体
    职业纪律：调整职业实践的行为方式
# 科技职业道德的特征
- 想象品质
- 创新气质
- 坚强意志
# 科技人员职业道德的基本要求
- 探索创新是科技活动中最突出的特点;探索创新是科技人员必备的心理品质。
  
- 热爱专业、忠于职责，是科技职业道德的基本原则，是科技人员从事科技
   劳动的基本道德要求。
   
- 热爱专业、忠于职责，是集体主义原则在科技职业道德中的具体体现，是从社会主义道德原则中引申出来的，它显示了科技职业道德的本质特征。
  
- 同心同德、团结协作，最根本的是增强个人的集体观念、集体意识。
  同心同德、团结协作，是当代科学技术高度社会化和高度综合化发展趋势的客观要求，更是社会主义道德原则在科技职业活动中的又一具体体现。
  
- 谦虚谨慎、尊重他人，是科技人员在处理人际关系中必须遵循的道德准则，是科技人员搞好团结协作的思想基础。
  
- 造福人民、振兴祖国是科技职业道德的核心内容，是科技人员进行科技活动的出发点和归宿，是科技人员创造成就的巨大动力。（重点）
