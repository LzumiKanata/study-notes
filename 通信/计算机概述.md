# 计算机的发展

- 五代发展
    第一代：电子管计算机（体积大）
    
    第二代：晶体管计算机（通电与不通电的关系）
    
    第三代：集成电路计算机（晶体管镶嵌在电路板上/技术不行，体积较大）
    
    第四代：大规模或查大规模（技术精进，电路板大小为3-4 nm）
    
    第五代：超大规模计算机（）

- 口诀：一直五代：电晶集大超

- 计算机的发展朝这三个方向发展
    巨型化（超级计算机）
    微型化（掌上笔记本）
    网络化（设备与计算机共享数据）

# 计算机的特点

- 运算速度快

- 运算精度高（取决于电脑有多少位，如32位/64位计算机）

- 存储功能强（硬盘）

- 具有记忆和逻辑判断能力（将数据存储，包括过程数据与结果数据。能够对条件进行判断）

- 具有自主运行的能力（运行后可以不管，程序运行的时候称为进程，进程在后台执行）

# 计算机的分类

## 四个分类原则
- 按工作原理
    数字计算机（处理数字信号，0和1）
    模拟计算机（处理模拟信号）

- 按用途分类
    专用计算机（运用在专业领域）
    通用计算机（用途广泛）

- 按规模分类（按物理尺寸分类）
    巨型机
    小巨型机
    大型机
    小型机
    工作站（客户端）和微型机

- 按使用方式
    掌上计算机
    笔记本计算机
    台式计算机
    网络计算机
    工作站（客户端）、服务器、主机

# 计算机的应用

- 科学计算（数值计算）
    大量数值计算问题

- 数据处理（信息管理）
    采集、管理、分析、处理大量数据并产生新的信息的过程

- 计算机辅助工程
    提高产品设计（CAD、PS）、生产和测试工程的自动化水平

- 过程控制（实时控制）
    控制对象进行自动调节或自动控制

- 人工智能
    模拟人类的智能活动

- 网络应用
    社会发展的必然趋势（资源的共享）
